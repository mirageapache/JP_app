# 設計系統

> 對應規劃書：`japanese-app-project-plan.md` v0.4
> 頁面範例：`ui-mockups/index.html`（用瀏覽器開啟，可切換淺色／深色）
> 本文件定義的 token 以 CSS 變數實作，與 UI 函式庫無關；P0 選定 Vant 4 或 Konsta UI 後，再將 token 對應到該函式庫的主題變數。

## 1. 設計理念：練習帳

整個 App 的視覺以日本小學生的**練習帳**（れんしゅうちょう）為原型：米白紙張、墨色文字、田字格，以及老師批改用的**朱色**。

| 原則 | 說明 |
|---|---|
| **紙與墨** | 背景是溫和的米白，不用純白；文字是偏暖的墨色，不用純黑。長時間看也不刺眼 |
| **朱色只用來批改** | 朱色專門表示「錯誤／需要注意」，像老師的紅筆。其他地方不用朱色，讓它一出現就有意義 |
| **字是主角** | 練習中的假名、單字用大字級、教科書體顯示，介面元素退到旁邊 |
| **單手可操作** | 通勤時單手使用：主要操作放在畫面下半部，按鈕高度至少 44pt |
| **安靜的回饋** | 答對不放煙火，以墨色沉穩呈現；答錯以朱色短暫提示後讓你重來。不製造壓力 |

### 2.2 SRS 評分色

四個評分按鈕各有固定顏色，全 App 一致，讓使用者靠顏色就能找到按鈕：

| 評分 | Token | 顏色 |
|---|---|---|
| 重來 | `--c-again` | 同 `--c-shu` |
| 困難 | `--c-hard` | 同 `--c-warn` |
| 良好 | `--c-good` | 同 `--c-ok` |
| 簡單 | `--c-easy` | 淺色 `#2F6DAE`／深色 `#7FB3EA` |

### 2.3 使用規則

- 一般文字與背景的對比至少 4.5:1；`--c-ink-3` 只用於不影響理解的輔助文字
- 顏色不是唯一的資訊來源：正確／錯誤同時搭配圖示或文字（例如 ✓、「再寫一次」）
- 深色模式跟隨系統設定（`prefers-color-scheme`），App 內不另設開關
- 深色模式不是把淺色反轉：紙色變成暖黑、朱色與藍色提亮，避免在暗處刺眼

## 3. 字體

### 3.1 字體家族

| Token | 字體 | 用途 |
|---|---|---|
| `--font-ui` | `-apple-system`, `"PingFang TC"`, `"Noto Sans TC"`, `"Microsoft JhengHei"`, sans-serif | 介面文字（繁體中文） |
| `--font-ja` | `"Hiragino Sans"`, `"Hiragino Kaku Gothic ProN"`, `"Noto Sans JP"`, `"Yu Gothic"`, sans-serif | 一般日文內容（例句、單字列表） |
| `--font-ja-display` | `"Klee One"`, `"Hiragino Mincho ProN"`, `"Yu Mincho"`, serif | 練習對象的大字（假名、單字題目） |

**為什麼練習用的大字要用 Klee One？**
一般的黑體、明體字型，假名的字形和手寫不同（例如 さ、き 的下方在黑體中是相連的，手寫時是分開的）。Klee One 是**教科書體**風格的字型，字形接近手寫與學校教的寫法，學寫字時看到的就是正確的形狀。正式版會將字型檔放進 App 一起快取，離線也能顯示（授權為 SIL Open Font License）。

**日文內容一律標示 `lang="ja"`**（規劃書 6.6），iOS 才會用日文字型顯示漢字。

### 3.2 字級

| Token | 大小 / 行高 | 用途 |
|---|---|---|
| `--fs-caption` | 12 / 16 | 時間戳記、圖表標籤 |
| `--fs-small` | 13 / 18 | 輔助說明 |
| `--fs-body` | 15 / 22 | 內文、列表 |
| `--fs-callout` | 17 / 24 | 列表標題、按鈕 |
| `--fs-title` | 20 / 28 | 頁面標題 |
| `--fs-title-lg` | 26 / 34 | 首頁大標、統計數字 |
| `--fs-word` | 40 / 52 | 單字題目 |
| `--fs-kana` | 96 / 1 | 辨識題的假名 |
| `--fs-kana-xl` | 160 / 1 | 假名詳細頁 |

- 數字一律使用等寬數字（`font-variant-numeric: tabular-nums`），計數變動時不會跳動
- 讀音標注（`<rt>`）為本文的 50%，顏色 `--c-ink-2`

## 5. 版面與導覽

### 5.1 畫面結構

```
┌───────────────────────┐
│  頂部列（標題、操作）   │  ← 避開瀏海：padding-top 加 safe-area-inset-top
├───────────────────────┤
│                       │
│  內容（可捲動）         │
│                       │
├───────────────────────┤
│  底部分頁列            │  ← 避開 Home 指示條：padding-bottom 加 safe-area-inset-bottom
└───────────────────────┘
```

- 最大寬度 480，在 iPad 或電腦上置中
- 使用 `100dvh`，避免 iOS 網址列造成高度錯誤

### 5.2 底部分頁列（5 個分頁）

| 分頁 | 內容 | 階段 |
|---|---|---|
| 今日 | 每日學習入口、進度、同步狀態 | P1b |
| 假名 | 50 音表、假名詳細、易混淆、弱點專練 | P1a |
| 單字 | 單字列表（主線／主題） | P2 |
| 文法 | 文法列表（依課次） | P3 |
| 統計 | 連續天數、完成度、弱點分析 | P3 |

設定從「今日」頁右上角的圖示進入。尚未開發的分頁先隱藏，不顯示空頁。

### 5.3 學習中的畫面（Session）

每日學習、測驗進入**全螢幕模式**：隱藏分頁列，頂部只留「關閉」與進度條，底部放作答或評分按鈕。讓注意力只在題目上。

```
┌───────────────────────┐
│ ✕   ▓▓▓▓▓░░░░░   12/30 │  ← 關閉、進度、剩餘
│                       │
│        題目            │  ← 畫面上半部
│                       │
├───────────────────────┤
│  作答區／評分按鈕       │  ← 畫面下半部（拇指可及）
└───────────────────────┘
```

## 7. 手寫練習的視覺規範

手寫是本 App 的核心，需要特別一致。

### 7.1 田字格

- 正方形，寬度 = 螢幕寬 − 左右各 24（保留邊距，避免觸發 iOS 邊緣返回手勢）
- 外框 1.5px `--c-line`；中央十字為 1px 虛線 `--c-grid`
- 描摹模式：範本字以 `--c-ink` 12% 透明度顯示
- 提示模式：只顯示下一筆的起點（藍色圓點）與方向

### 7.2 筆跡與回饋

| 狀態 | 呈現 |
|---|---|
| 書寫中 | 墨色 `--c-ink`，線寬 = 格寬的 4.5%，圓頭 |
| 該筆通過 | 筆跡平順地替換成標準筆畫形狀（150ms 淡入），墨色 |
| 位置偏差／方向錯誤 | 筆跡變朱色，左右輕晃 200ms 後淡出，下方顯示原因（例如「方向反了」） |
| 順序錯誤 | 同上，提示「這是第 3 筆，請先寫第 2 筆」 |
| 連錯 3 次 | 顯示該筆的藍色提示動畫（起點 → 終點），再讓使用者寫 |
| 全部完成 | 整個字以墨色完整呈現，下方出現評分列（附建議評分） |

### 7.3 筆順動畫

- 每一筆依序以 `stroke-dashoffset` 描出，每筆 500ms、間隔 150ms
- 正在描的筆畫為 `--c-primary`，描完轉為 `--c-ink`
- 起點標示小號筆畫序號（1、2、3…）

## 8. 動態

| Token | 值 | 用途 |
|---|---|---|
| `--dur-fast` | 120ms | 按壓、開關 |
| `--dur-base` | 200ms | 狀態切換、選項回饋 |
| `--dur-slow` | 320ms | 面板進出、頁面轉場 |
| `--ease` | `cubic-bezier(.2,.7,.2,1)` | 一般 |

- 使用者開啟「減少動態效果」（`prefers-reduced-motion`）時，晃動與轉場改為直接切換；筆順動畫保留（它是內容，不是裝飾），但可暫停

## 9. 文案

- 介面語言為繁體中文（台灣用語）：「設定」不是「設置」、「資料」不是「數據」
- 口吻平實、鼓勵但不誇張：「今天的目標完成了」，不用「太棒了！！🎉」
- 錯誤訊息說明**怎麼做**：「方向反了，從左上往右下寫」，而不是「錯誤」
- 日文術語第一次出現時附中文：「振り仮名（讀音標注）」

---

## 10. 無障礙

- 觸控目標至少 44×44pt
- 所有圖示按鈕都有 `aria-label`
- 正確／錯誤不只靠顏色，同時有圖示與文字
- 假名、單字題目元素加上 `lang="ja"`，讓 VoiceOver 以日文朗讀
- 支援系統的「粗體文字」；介面文字使用 rem，字級隨系統設定放大時版面不破
