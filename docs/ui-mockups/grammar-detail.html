第 14 課

N5今天的新卡

〜てください

請（對方）做～

接續

動詞て形＋ください
書かく → 書かいて → 書かいてください

說明

用來禮貌地請求對方做某件事。語氣比命令形柔和，日常對話、店員對客人都很常用。

例句

  • ここに名前なまえを書かいてください。

    請在這裡寫名字。

  • ちょっと待まってください。

    請稍等一下。

  • もう少すこしゆっくり話はなしてください。

    請再說慢一點。

對長輩或上司要更客氣時，可以用「〜ていただけませんか」（第 26 課）。
