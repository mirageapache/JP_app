# 開發階段與工作項目

> 依據：`japanese-app-project-plan.md` v0.4 第 10 章
> 用法：每完成一項就打勾；每個階段結束後實際使用一週，再進入下一階段。
> 時程不預設，由實際投入時間決定。

## 階段總覽

| 階段 | 目標 | 完成標準 |
|---|---|---|
| P0 驗證 | 確認技術上最不確定的事可行 | P0 驗證清單全部通過；UI 決定沿用自訂元件 |
| P1a 平假名自由練習 | 手寫引擎可用並經實際調校 | 可自由練習平假名手寫 |
| P1b 每日使用 | 開始每天用它學習 | 可每日練習平假名，且有備份（程式完成，待實測；見 p1-verification.md） |
| P1.5 假名完整版與同步 | 假名完整、資料自動上雲 | 假名可完整練習；紀錄自動同步（程式完成，待實測） |
| P2 單字 | N5 單字每日複習 | 單字每日複習流程完整 |
| P3 文法與測驗 | 完整學習閉環 | N5 文法、測驗、統計可用 |
| P4 N4 | 擴充到 N4 與漢字手寫 | N4 內容可每日使用 |
| P5 以後 | N3～N1 | 每個等級一個階段 |
