# P1 驗證指南（P1a／P1b／P1.5）

> 測試裝置：iPhone 主畫面 App，`https://jp-app-ebf.pages.dev/`
> 用法：照順序測，結果填在「結果」欄；有問題時把畫面截圖或除錯面板（設定 → 連點版本號 5 次）的內容一起回報。

## 0. 更新到新版

- [ ] push 後等 Cloudflare 部署完成，從主畫面開啟 App；若出現「有新版本可用」按「更新」，沒有的話完全關閉 App 再開
- [ ] 第一次開啟會出現引導頁（加入主畫面的說明）→ 按「開始使用」

## 1. 每日學習（P1b）

| # | 步驟 | 預期 | 結果 |
|---|---|---|---|
| 1-1 | 首頁顯示今天的「待複習／新卡／預估時間」 | 第一天：待複習 0、新卡 5 | |
| 1-2 | 按「開始學習」→ 辨識題：看字選讀音 | 答對後評分列建議「良好」；答錯建議「重來」，該卡在這一輪結尾會再出現 | |

| 1-6 | 隔天再開 | 新卡 5 張（下一行），前一天的卡到期複習；**讀卡熟了（非當天）之後，手寫題才會出現** | |
| 1-7 | 手寫題（第 2～3 天起）| 新卡用描摹、複習用空白；答錯重出時用「提示」（起點與方向） | |

## 已知限制

- 手寫判定門檻只以一個字（あ）的 14 筆手指筆跡校準過；請用調校模式多收集幾個字（ぬ、そ、き、ふ、が），匯出後交給開發者調整
- そ、り 的替代寫法尚無筆畫資料
- 片假名會在平假名全部導入後才開始出現在每日新卡；想先練可到 50 音表自由練習
